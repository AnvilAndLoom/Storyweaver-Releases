# Anvil and Loom: Storyweaver

A local-first studio for solo role-playing, emergent storytelling, and building your worlds.

## Download

[Download the latest Windows release](https://github.com/AnvilAndLoom/Storyweaver-Releases/releases/latest)

Choose the file ending in **windows-x64-setup.exe**. The other files are used by Storyweaver's updater and do not need to be opened.

This repository contains official installers, update metadata, and release notes. The development source is maintained separately.

## Updating Storyweaver

Starting with **0.9.2**, Storyweaver checks for updates in the background. Open **App updates** from the Tapestry library or Settings to check immediately. Choose **Download update**, then **Save & restart to update** when you are ready.

The application saves your open Tapestry before installing. If saving fails, the update is postponed. Your stories and settings remain on your computer.

If you have an older version, install 0.9.2 or later manually once to enable this feature. Use the same installation folder as before.

## Beta notes

- Windows 10/11, 64-bit.
- This beta is playable through December 31, 2026. Reading and export remain available after the beta ends.
- The installer is currently unsigned. Windows may display an unknown-publisher warning.
- AI assistance is optional. You can play and write without connecting an AI account.
